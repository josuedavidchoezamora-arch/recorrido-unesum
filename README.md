# Recorrido virtual UNESUM

Visor web del recorrido de la propuesta de pintura institucional del campus UNESUM (Jipijapa): fotografias del estado actual (antes) y renders de la propuesta (despues) ubicados sobre el terreno del modelo BIM.

Publicado con GitHub Pages: https://josuedavidchoezamora-arch.github.io/recorrido-unesum/
